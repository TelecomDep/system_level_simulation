# Порядок запуска компонентов системы

### Запуск коры
В директории /docker проекта srsRAN_5G:

```sudo docker  compose  up  --build  5gc```

### Запуск базы
В директории /build/apps/gnb проекта srsRAN_5G:

```sudo  ./gnb  -c  gnb_zmq.yaml```

### Запуск пользователей
В директории /build/srsue/src проекта srsRAN_4G:

```sudo  ./srsue  ./ue1_zmq.conf```
```sudo  ./srsue  ./ue2_zmq.conf```

### Cборка и запуск брокера

В директории /zmq_broker проекта system_level_simulation:

```
mkdir build
cd build
cmake ..
make
./main
```

Альтернативно:

Для нового брокера просто 
make "название файла без расширения"
./название файла

### Матлаб сервер

Файл с матлаб сервером в директории /matlab


### Примечание

Предполагается запуск с 1 базой и 2 пользователями. Для изменения кол-ва пользователей необходимо внести изменения в матлаб файл и конфиг брокера, который находится в
директории /configs


### Работа нового брокера
код нового работающего прокера в: broker.cpp
Брокер стабильно работает с 5 пользователями

На пользователей накладывается pathloss и noise

Pathloss расчитывается на основе модели расчёта PL cost231-Hata(Rural)
Расстояния для расчёта Pathloss заданы константно для каждого UE в км.

сборка:
g++  broker.cpp -lzmq -lvolk -o test_broker

в новом брокере количество пользователей на данный момент регулируется переменной "ue_num"

Важно! Пользователи идут из конфигов следующие: ue11, ue12, ue13, ue14 ...
